Política de Privacidade - Claude Emails

Última atualização: 5 de novembro de 2026

O Claude Emails é uma ferramenta de uso pessoal de Tiago Rabelo, que só ele usa para ler e gerenciar as próprias contas de e-mail. Ela não é oferecida a outras pessoas.

Dados acessados

Com autorização do titular, a ferramenta lê, organiza, rascunha e envia e-mails nas contas Gmail do próprio titular.

Uso

Os dados servem só para atender pedidos do próprio titular. Eles não são vendidos, compartilhados com terceiros nem usados para publicidade.

Armazenamento

As autorizações ficam guardadas só no computador pessoal do titular. Não há servidor nem banco de dados com o conteúdo dos e-mails.

APIs do Google

O uso das informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Revogação

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions.
